# Arkania

Juego de aventuras para practicar las cuentas de 3º de primaria.

- `index.html`: el juego completo en un solo archivo.
- `docker-compose.yml`: stack para Portainer. Sirve el juego en el puerto 8085 y descarga `index.html` de este repositorio cada 5 minutos.

Para actualizar el juego basta con cambiar `index.html` en la rama `main`.
